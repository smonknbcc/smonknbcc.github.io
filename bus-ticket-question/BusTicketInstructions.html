Bus Ticket Form

Use HTML and CSS to create the form shown.

Restrictions

  • No tables.
  • No Bootstrap (or similar).
  • No JavaScript.

Design

  • The layout must match the provided screenshot (row structure, alignment, and grouping).
  • Each horizontal grouping in the form is considered a “row” (as shown in the screenshot).
  • Two-tone background color pattern on rows.
  • The first three rows must use Flexbox to arrange all controls horizontally on a single row.
  • The last five rows must use CSS Grid with two columns: a label on the left and an input on the right.
    • All labels must align vertically in a single column, and all inputs must have the same width.

HTML Features - General

  • The entire form, including the “Submit” and “Reset” buttons, must be inside a <form> tag.
  • All inputs must have associated <label> elements.
  • Ticket type radio buttons act as a group - i.e., only one can be selected at a time.
    • The options are: Adult, Child, Senior, Student.
  • Origin and Destination drop-downs should show the following places:
    • Bathurst
    • Campbellton
    • Edmundston
    • Fredericton
    • Miramichi
    • Moncton
    • Saint Andrews
    • Saint John
    • Saint Stephen
    • Sussex
    • Woodstock
  • Departing and Returning inputs are type date.
  • Email input is type email.
  • Phone input is type text and shows placeholder string NNN-NNN-NNNN.
  • Bags input is type number.

HTML Features - Validation

  • The following inputs are required (may not be left empty):
    • Departing
    • First Name
    • Last Name
    • Email
    • Phone
    • Bags
  • Phone input must match the format shown in the placeholder.
    • (Hint: use regex ^\d{3}-\d{3}-\d{4}$).
  • Bags input must be greater than or equal to 0.
  • No validation is required to prevent selecting the same Origin and Destination. (That would require JavaScript.)

Tests

  1. Press the Reset button. Confirm that inputs in rows 4+ are empty.
  2. Verify that only one ticket type (Adult, Child, Senior, Student) can be chosen.
  3. Verify that all required places are shown in both drop-down lists.
  4. Press Reset and then press Submit. Browser should warn that Departing date cannot be empty.
  5. Select a Departing date and press Submit. Browser should warn that First Name cannot be empty.
  6. Enter a first name and press Submit. Browser should warn that Last Name cannot be empty.
  7. Enter a last name and press Submit. Browser should warn that Email cannot be empty.
  8. Enter an invalid email address and press Submit. Browser should warn that Email is invalid.
  9. Enter a valid email address and press Submit. Browser should warn that Phone cannot be empty.
  10. Enter an invalid phone number and press Submit. Browser should warn that Phone does not match pattern.
  11. Enter a valid phone number and press Submit. Browser should warn that Bags cannot be empty.
  12. Enter -7 for Bags and press Submit. Browser should warn that Bags must be at least 0.
  13. Enter 3 for Bags and press Submit. You should see a popup window indicating success.
